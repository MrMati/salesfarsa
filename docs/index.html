02

Model, interfejs i procesy

Aplikacja prowadzi ewidencję nieruchomości i usług, oblicza podatek, dobiera wykonawcę do terminu i kwalifikacji, rejestruje płatności i wykonanie usługi. 12 obiektów custom, standardowy Account, 97 pól custom na obiektach danych oraz 1 Platform Event z 4 polami.

Nieruchomości i firmy

Właściciel nieruchomości, klient i firma wykonawcza są rozróżnionymi rolami Account.

Usługi i kwalifikacje

Katalog usług, aktywne oferty firm oraz relacje n:m kwalifikacji wymaganych i posiadanych.

Zapytanie i rezerwacja

Quote rekomenduje firmę; Screen Flow zapisuje fakturę z terminem i wybranym wykonawcą.

Faktura i podatek

Podatek przy tworzeniu i zmianie netto/kraju; symulacja LWC nie modyfikuje zapisanych danych.

Rozliczenie nieruchomości

Aura prezentuje sumę widocznych faktur brutto. Globalne Total_Cost__c uwzględnia wyłącznie Paid i po Lab 7 jest wskaźnikiem administracyjnym.

Zmiany i powiadomienia

Dwa Flow i Platform Event, ślad odbioru, deduplikacja oraz opcjonalny e-mail do właściciela.

E04Błąds. 21

LastModifiedById oraz warunkowe OwnerId

W materiale

Lista pól zawiera LastModifiedBy jako identyfikator oraz sugeruje OwnerId na każdym obiekcie.

E06Doprecyzowanies. 24, 26–27

Relacje i brakujące wykonanie usługi

W materiale

Diagram nie precyzuje typów relacji ani momentu wykonania usługi. Nazywa też dwa Master-Detail jedyną drogą do n:m.

Poprawka / wyjaśnienie

W rozwiązaniu Account_Service__c jest obiektem łączącym z dwiema relacjami Master-Detail. n:m można też modelować relacjami Lookup, z innymi zasadami własności i usuwania. Pozostałe relacje są Lookup. Dodano Service_Execution__c z nieruchomością, usługą, wykonawcą i datą/czasem; bez tych danych status Completed jest blokowany.

E07Doprecyzowanies. 26–27, zad. 1.2–1.4

„Wykonawca” i „klient” to różne role

W materiale

Invoice__c.Account_Id__c i Property__c.Owner__c nie wskazują jednoznacznie firmy wykonującej usługę.

Poprawka / wyjaśnienie

Account_Id__c faktury oznacza odbiorcę, Owner__c nieruchomości jej właściciela, a Service_Execution__c.Provider__c firmę wykonującą usługę. Nie wyznaczaj wykonawcy na podstawie właściciela nieruchomości. Jeden Account może pełnić różne role.

Weryfikacja Dane demonstracyjne zawierają osobno klienta i wykonawcę; wykonanie wskazuje firmę demonstracyjną.

E08Błąds. 29

Id może mieć 15 albo 18 znaków

W materiale

Id opisano wyłącznie jako osiemnastoznakowy identyfikator.

Poprawka / wyjaśnienie

Salesforce obsługuje 15-znakową postać rozróżniającą wielkość liter i 18-znakową postać z sumą kontrolną. W Apex używaj typu Id; nie obcinaj identyfikatorów i nie traktuj ich jak liczb.

Zmienna „number” jest zastrzeżona

W materiale

Pętla deklaruje for (Integer number : numbers).

Poprawka / wyjaśnienie

Zmień nazwę zmiennej, np. na item. Samo ignorowanie wielkości liter w Apex nie omija słów zastrzeżonych.

for (Integer item : values) {
    // ...
}

Weryfikacja Próba oryginału: Identifier name is reserved: number (probe-figure-2-1.json).

/** Labs 2.1–2.4. Percent fields use percentage points in Apex: 23 means 23%.
 * Labs 3–4: insert and changes of amount/country; this is a teaching model, not a tax engine.
 * with sharing enforces record sharing; CRUD/FLS remain the caller's concern.
 */
public with sharing class TaxCalculationService {
    public static final Decimal DEFAULT_TAX_RATE = 23;
    public class TaxInputException extends Exception {}

    // Preserved solution to exercise 2.1; later exercises use configured rates.
    public static Decimal calculateFixedTax(Invoice__c invoice) {
        if (invoice == null || invoice.Amount__c == null || invoice.Amount__c < 0) {
            throw new TaxInputException('A nonnegative net amount is required.');
        }
        return (invoice.Amount__c * DEFAULT_TAX_RATE / 100).setScale(2, RoundingMode.HALF_UP);
    }

    // Exercise 2.3: query matching rates, also reusable for a singleton country set.
    public static List<Country_Tax_Rate__c> findTaxRates(Set<String> countries) {
        if (countries == null || countries.isEmpty()) return new List<Country_Tax_Rate__c>();
        return [SELECT Country__c, Tax__c FROM Country_Tax_Rate__c WHERE Country__c IN :countries];
    }

    public static void calculateTax(Invoice__c invoice) {
        if (invoice == null) throw new TaxInputException('Invoice is required.');
        calculateTaxes(new List<Invoice__c>{invoice});
    }

    public static void calculateTaxes(List<Invoice__c> invoices) {
        if (invoices == null || invoices.isEmpty()) return;
        Set<String> countries = new Set<String>();
        for (Invoice__c invoice : invoices) {
            if (invoice == null) throw new TaxInputException('Invoice list contains null.');
            if (!String.isBlank(invoice.Country__c)) countries.add(invoice.Country__c);
        }
        Map<String, Decimal> rates = new Map<String, Decimal>();
        Set<String> duplicates = new Set<String>();
        for (Country_Tax_Rate__c rate : findTaxRates(countries)) {
            if (rates.containsKey(rate.Country__c)) duplicates.add(rate.Country__c);
            rates.put(rate.Country__c, rate.Tax__c);
        }
        for (Invoice__c invoice : invoices) {
            if (invoice.Amount__c == null || invoice.Amount__c < 0) {
                invoice.addError('A nonnegative net amount is required.');
            } else if (String.isBlank(invoice.Country__c)) {
                invoice.addError('Invoice country is required.');
            } else if (duplicates.contains(invoice.Country__c)) {
                invoice.addError('Multiple tax rates configured for ' + invoice.Country__c + '.');
            } else if (!rates.containsKey(invoice.Country__c)) {
                invoice.addError('No tax rate configured for ' + invoice.Country__c + '.');
            } else {
                Decimal rate = rates.get(invoice.Country__c);
                if (rate == null || rate < 0 || rate > 100) {
                    invoice.addError('Tax rate must be between 0 and 100 percent.');
                    continue;
                }
                invoice.Tax__c = rate;
                invoice.Tax_Amount__c = (invoice.Amount__c * rate / 100).setScale(2, RoundingMode.HALF_UP);
            }
        }
    }
}

import { LightningElement, api } from 'lwc';
import { FlowAttributeChangeEvent } from 'lightning/flowSupport';
import getAvailableProviders from '@salesforce/apex/InvoiceLabController.getAvailableProviders';
export default class ProviderPicker extends LightningElement {
    @api serviceId;
    @api startAt;
    @api endAt;
    _providerId;
    @api get providerId() { return this._providerId; }
    set providerId(value) { this._providerId=value; }
    options=[]; loading=true; error;
    connectedCallback() { this.load(); }
    async load() {
        this.loading=true; this.error=undefined;
        try {
            this.options=await getAvailableProviders({serviceId:this.serviceId,startAt:this.startAt,endAt:this.endAt});
            if (!this.options.some(option=>option.value===this.providerId)) this.select(null);
        } catch(error) { this.options=[]; this.error=error.body?.message || error.message || 'Nie udało się sprawdzić dostępności.'; }
        finally { this.loading=false; }
    }
    get hasOptions() { return this.options.length>0; }
    change(event) { this.select(event.detail.value); }
    select(value) { this._providerId=value; this.dispatchEvent(new FlowAttributeChangeEvent('providerId',value)); }
    refresh() { this.load(); }
    @api validate() {
        return {isValid:!this.loading && Boolean(this.providerId) && this.options.some(option=>option.value===this.providerId),errorMessage:'Wybierz dostępną firmę albo wróć i zmień termin.'};
    }
}
